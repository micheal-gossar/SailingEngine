WEATHER SYSTEM CLASS DESIGN
===========================

Class:

    WeatherSystem

Purpose:

    Own deterministic time-varying wind, gusts, precipitation, fog, cloud, and
    ocean-driving parameters.

Public API:

    static Result<WeatherSystem,WeatherError> Create(
        const WeatherConfiguration&);
    Result<void,WeatherError> SetTargetPreset(
        WeatherPresetId, DurationSeconds transition);
    void FixedUpdate(TickId, FixedDeltaSeconds);
    WindSample SampleWind(const WorldPosition&) const;
    WeatherSnapshot CurrentSnapshot() const;
    WeatherSnapshot Save() const;
    void Restore(const WeatherSnapshot& snapshot);

WeatherState:

    Base wind direction/speed.
    Gust amplitude/frequency.
    Cloud coverage/density.
    Fog density/color.
    Precipitation.
    Lightning probability.
    Ocean wave target parameters.
    Sun visibility.

Behavior:

    Blend presets continuously.
    Generate gusts from deterministic seeded noise.
    Sample regional modifiers.
    Publish immutable state once per fixed update.
    Publish one immutable WeatherSnapshot at P4. Ocean forcing, render systems,
    AI, and audio presentation consume it at their phases; WeatherSystem calls
    none of those consumers.

Rules:

    Gameplay samples use fixed simulation time.
    Render effects may interpolate between states.
    Wind vectors use one documented world convention.
    Saving/restoring preserves seed and transition progress.
    Consumers cannot modify current state.

Errors:

    UnknownPreset
    InvalidTransitionDuration
    InvalidWindValue
    CorruptSnapshot

Tests:

    Deterministic gust samples.
    Smooth transition endpoints.
    Save/restore equivalence.
    Wind direction normalization.
    No discontinuity across regional boundaries.
    Correct ocean target publication.

Dependencies:

    AssetManager
    TickId/FixedDelta values

Canonical integration contract:

    Normative weather-state owner. Wind is m/s toward motion in root world
    axes; source "from" degrees convert once on asset ingestion. Other fields
    declare SI/normalized dimensions. Authoritative variation uses a versioned
    counter RNG derived from WorldSeed128, region, purpose, and TickId; render
    time/randomness never enters. Save provider stores preset/transition/seed
    state but SaveSystem is not a runtime dependency.

    Invalid preset/duration/physical value, AssetId, or corrupt restore returns
    WeatherError transactionally. See ..\CANONICAL_CONVENTIONS.txt,
    ..\FRAME_THREADING_MODEL.txt, and INDEX.txt.
