TIME OF DAY CLASS DESIGN
========================

Class:

    TimeOfDaySystem

Purpose:

    Advance calendar/solar time and provide deterministic sun, moon, tide phase, and scheduled-time events.

Public API:

    SetDateTime(value);
    StepFixed(TickId,FixedDeltaSeconds);
    SetRate(multiplier);
    Pause(bool);
    Snapshot() const;
    Schedule(time,event);
    Serialize()/Deserialize();

Internal state and components:

    - calendar epoch.
    - fractional simulation seconds.
    - latitude/longitude.
    - rate.
    - event min-heap.
    - sequence IDs.

Lifecycle and ownership:

    world owns service; snapshots are values; scheduled callbacks represented as game events, not function pointers in saves

Error behavior:

    Invalid date/rate/epoch, duplicate schedule ID, capacity, migration, and
    corrupt restore return TimeOfDayError. Failed restore leaves prior state.

Threading and timing constraints:

    fixed simulation step; integer/fixed representation prevents drift; render interpolates snapshot; rate changes boundary-applied

Dependencies:

    - TickId/FixedDelta values from SimulationClock.
    - GameplayCommandBus consumes scheduled GameEvent values.
    - SaveSystem consumes registered immutable snapshots; no runtime dependency.

Tests:

    - solar direction known dates.
    - rate/pause.
    - event once/order.
    - large advance.
    - save round-trip.
    - invalid date/rate.

Implementation rules:

    - Keep implementation-only types out of public headers.
    - Use RAII and generational IDs; do not expose owning raw pointers.
    - Validate descriptions before allocating or mutating state.
    - Publish complete snapshots/generations rather than partially updated data.
    - Add diagnostics for failure context without making logging a dependency
      of correctness.

Canonical integration contract:

    Normative calendar/solar-time owner. P4 advances from integer/rational fixed
    time and publishes TimeOfDaySnapshot; render interpolates only copied sun/
    moon presentation values. Scheduled entries are typed data and emit ordered
    P8 events, never saved function pointers/callback ownership. Tide phase is
    calculated by OceanEnvironmentForcing from the shared persisted epoch;
    this system does not own ocean tides.

    See ..\core\37_simulation_clock.txt, ..\FRAME_THREADING_MODEL.txt, and INDEX.txt.
