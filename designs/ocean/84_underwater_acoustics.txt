UNDERWATER ACOUSTICS CLASS DESIGN
=================================

Class
-----

    UnderwaterAcoustics

Purpose
-------

Model scalable underwater sound propagation for vessel noise, surf, weather,
marine animal vocalization, sonar-like gameplay if present, and listener
rendering, using water-column physics distinct from visual fog.

Public API
----------

    AcousticEmitterId RegisterEmitter(const UnderwaterEmitterDescription&);
    AcousticReceiverId RegisterReceiver(const UnderwaterReceiverDescription&);
    void UpdateEmitter(AcousticEmitterId, const AcousticEmitterState&);
    void QueueTransient(const UnderwaterSoundEvent&);
    void Advance(OceanTick);
    AcousticTransfer QueryTransfer(
        AcousticEmitterId, AcousticReceiverId, FrequencyBandMask) const;
    void BuildAudioFrame(AudioFrameBuilder&) const;
    void Unregister(AcousticObjectId);

Key data structures
-------------------

SoundSpeedProfile stores depth knots of temperature, salinity, pressure-derived
sound speed and uncertainty. AcousticCell stores bathymetry, surface state,
bottom loss/material, volume absorption/turbidity, ambient bands, and neighbors.
EmitterState stores cell/local position, depth, directivity, one-third-octave
source levels, Doppler velocity, semantic class, and priority. PropagationPath
stores delay, band attenuation, phase/coherence class, arrival direction,
surface/bottom interactions, and generation. AnimalCall carries species/group,
call id, intent category, and cooldown without encoding behavior in AudioSystem.

Algorithms and models
---------------------

Internal amplitudes are linear acoustic pressure Pa or power W by frequency
band; public source levels explicitly use dB re 1 microPa at 1 m and convert
once. Distances are metres, delay seconds, sound speed m/s, absorption dB/km in
assets converted to nepers/m internally, and Doppler uses radial m/s with the
sign in file 87. Optical turbidity is not an acoustic coefficient: bubbles,
sediment, and organisms require separately calibrated acoustic band models.

Near field uses spherical/cylindrical spreading transition, frequency-dependent
seawater absorption, Doppler, surface/bottom reflection loss, bubble attenuation,
and terrain line-of-sight. Medium range traces a bounded fan of refracted rays
through piecewise sound-speed profiles with bathymetry/surface interactions.
Far/low quality uses precomputed cell transmission graphs parameterized by
bands/depth. Cross-fade methods by path confidence/energy, not distance-only
volume hacks. Shallow surf/harbor reverberation uses late-energy parameters.

Ambient fields combine wind/sea state, rain, surf/breaking, biological sources,
and vessels in power space per band. Cavitation and propulsor spectra come from
interaction/vessel state. Animal communication requests paths and receives
delayed perceived stimuli; sound does not transmit instantly through occluded
terrain. Audio rendering converts paths to delays, filters, convolution/
reverberation sends, direction, and air-water interface transmission.

Wave-surface roughness changes reflection/scattering statistics at acoustic
update rate; breaker/bubble fields add band attenuation and ambient noise
without sampling individual visual particles. Paths carry environment,
bathymetry, surface, emitter, and receiver generations. Path interpolation
preserves delay causality and power: a newly shorter route cannot deliver an
event before its physical propagation time.

Update rates, threading, and GPU ownership
-----------------------------------------

Emitter transforms latch at 30-60 Hz. Propagation graphs update at 2-10 Hz;
critical close paths at 20 Hz; AudioSystem interpolates parameters per audio
block. Ray/path jobs run on CPU JobSystem and publish immutable double buffers.
No Vulkan compute dependency is required; optional GPU visualization is
non-authoritative. The real-time audio callback allocates/locks nothing and
reads a bounded prepared AudioFrame only.

Lifecycle and dependencies
--------------------------

Stream AcousticCells with ocean/terrain cells after forcing/bathymetry profiles
are ready. Emitters use generational handles and survive temporary path failure.
On cell unload, retain boundary graph nodes until paths expire. AudioSystem owns
voices/DSP; UnderwaterAcoustics owns propagation/environment, and MarineAgent
Simulation owns call intent/cooldowns. See ..\audio\14_audio_system.txt,
..\world\26_terrain_system.txt, 73_ocean_environment_forcing.txt,
77_ocean_interaction_wakes.txt, 80_ocean_effects_system.txt, and
82_marine_agent_simulation.txt.

Failure and error behavior
--------------------------

Errors include StaleEmitter, InvalidSpectrum, MissingSoundSpeedProfile,
PathBudgetExceeded, AcousticCellUnavailable, UnitReferenceMismatch,
CausalityViolation, PathGenerationMismatch, and NonFiniteTransfer.
Unavailable paths fall back to a named conservative direct/occluded estimate
with low confidence; they do not become full-volume dry-air sounds. Budget
pressure prioritizes player safety/gameplay and nearby animal communication,
then holds/interpolates older paths. Audio callback underrun uses the last
bounded frame and records telemetry.

Deterministic and testing strategy
----------------------------------

Path candidate order and graph search tie breaks are stable; stochastic ambient
events use counter RNG. Tests cover reference seawater absorption, homogeneous
sound speed delay, refracted ray in a gradient, surface/bottom loss, island
occlusion, shallow reverberation, Doppler sign, moving source continuity,
air-water crossing, ambient power addition, animal call delay/stimulus,
cell-stream boundaries, save/replay of emitters, and audio-thread lock/allocation
guards.
Save/replay persists semantic emitter/animal cooldown state and queued physical
events with source tick, not audio-device voice phase. Replay regenerates paths
and requires equal delays/band transfers within tolerance across worker counts;
the final audio sample stream may vary only through a declared DSP backend.

Performance and scalability
---------------------------

Use frequency bands rather than per-frequency rays, cell transmission caches,
source clustering, receiver-centric path budgets, temporal coherence, shared
paths for schools, and rate tiers. Cap arrivals and DSP filters per receiver.
Scale ray count, graph resolution, path update rate, and late-reverb detail;
preserve speed-of-sound delay and safety-critical occlusion. Profile path jobs,
cache hit, emitters/receivers, rays, graph nodes, AudioFrame build time, callback
cost, stale paths, and confidence.

Integration points
------------------

Environment supplies thermohaline profiles; terrain/coast supply depth and
bottom material; ocean/effects supply sea state, breakers, rain, and bubbles;
vessels/interactions supply machinery/propulsor/cavitation; marine agents supply
calls and consume perceived stimuli. AudioSystem performs final mixing. Debug
tools visualize paths, delays, bands, occlusion, cell confidence, and budgets.

Engine-wide integration contract
--------------------------------

Normative propagation/environment owner, not AudioSystem voice/DSP owner.
P10 jobs publish immutable AcousticTransfer/AudioFrameBuilder values; the audio
callback consumes a prepared bounded frame only. Emitters/receivers are typed
generations with WorldPosition/TickId; semantic source intent remains with
vessels/agents. No visual turbidity or GPU readback substitutes acoustic state.
See ..\audio\14_audio_system.txt, ..\CANONICAL_CONVENTIONS.txt, and
..\ERROR_RESULT_POLICY.txt.
