OCEAN SURFACE RENDERER CLASS DESIGN
===================================

Class
-----

    OceanSurfaceRenderer

Purpose
-------

Render a geometrically coherent air-water interface from ocean simulation
snapshots using physically based reflection, transmission, absorption, sun
glitter, multiscale displacement, and coastline integration.

Public API
----------

    Result<void, OceanRenderError> Initialize(
        const OceanSurfaceRenderDescription&);
    void SetQuality(const OceanSurfaceQuality&);
    void AddPasses(RenderGraphBuilder&, const OceanRenderSnapshot&,
                   const ViewFamily&);
    OceanSurfaceStatistics Statistics() const;
    void OnDeviceRecreated();

Key data structures
-------------------

OceanSurfaceRenderDescription defines spectral cascade formats, projected-grid
budgets, BRDF/SSR/refraction policy, reflection probe inputs, underwater
interface policy, and fallback capabilities. SurfaceViewConstants contain
high/low camera/world origin, inverse matrices, previous transforms, water
datum, generation, jitter, and exposure. SurfaceTileDraw contains coastal/deep
masks, bathymetry/shore handles, tessellation/mesh LOD, displacement bounds, and
indirect draw fields. WaterOpticalProfile stores wavelength-banded refractive
index, absorption, scattering, roughness closure, and foam albedo.

Algorithms and models
---------------------

Use camera-centered projected grids/clipmap rings with skirts and conservative
FFT displacement bounds. Vertex evaluation samples deep displacement/Jacobian
and coastal state under one partition-of-unity mask; shore vertices follow wet/
dry boundaries and do not draw under terrain. Geometric normal comes from the
displaced surface derivatives. Screen derivatives add only unresolved normal
detail with matched variance and energy compensation.

The dielectric interface uses exact or fitted Fresnel from water IOR, a
rough-surface microfacet distribution whose slope variance comes from omitted
spectrum bands, and masking/shadowing. Reflection selection combines valid
planar/probe or ray-query result with temporally validated hierarchical SSR and
environment fallback. Refraction traces scene depth/opaque color with thickness
and exits into UnderwaterMediaRenderer attenuation; total internal reflection
is handled. Direct sun glitter integrates BRDF energy. Foam is a separate
coverage/mixture term and cannot brighten beyond accounted scattered energy.

Fresnel computes s- and p-polarized reflectances from incident/transmitted IOR
and averages them for the default unpolarized radiance path; it is not Schlick
with an arbitrary art constant. An optional high tier carries first-order
Stokes I,Q,U for sky/sun reflection and applies the interface Mueller terms
once; multiple scattering, foam, SSR, and probes depolarize unless their input
explicitly supplies polarization. No gameplay or visibility decision depends
on polarization. Brewster-angle and grazing behavior are reference-tested.

At the interface reflected plus transmitted power is bounded by incident power,
including the radiance eta-squared conversion. The transmitted path uses the
medium's wavelength-banded absorption/scattering and geometric water thickness;
surface tint is not multiplied a second time. Sun glitter, environment
reflection, SSR/probe choice, subsurface transmission, and foam have documented
multiple-importance/coverage ownership so they do not each add full energy.

Motion vectors use previous and current ocean phase/generation plus stable
world coordinates. Temporal history is rejected on origin, spectrum, wet/dry,
camera-cut, or tile generation changes. Alpha blending is avoided for the main
surface: it writes resolved color/depth with explicit transmission inputs.

Update rates, threading, and GPU ownership
-----------------------------------------

Render thread builds passes per view. Async compute creates FFT fields/mips and
surface classification; graphics draws after graph barriers. Renderer owns
persistent history, grids, descriptors, and optical profiles. RenderGraph owns
transient reflection/refraction/color targets and execution order. CPU culling
uses immutable snapshot bounds; no simulation mutation or synchronous readback.

Lifecycle and dependencies
--------------------------

Initialize after Renderer, RenderGraph, GpuResourceManager, MaterialSystem,
DeepWaterSpectralOcean GPU resources, and UnderwaterMediaRenderer contracts.
Quality changes create new compatible resources and switch at frame boundary.
Device loss drops histories and deterministically rebuilds spectra/resources.
Shutdown retires through FrameManager after the generation's GpuCompletionSet.

Failure and error behavior
--------------------------

Errors include UnsupportedFormat, MissingOpaqueInputs, InvalidOpticalProfile,
SnapshotGenerationMismatch, ReflectionUnavailable, HistoryInvalid, and
GpuAllocationFailed. InvalidPolarizationState and OpticalEnergyViolation are
diagnostic validation failures. Feature fallback is ordered: ray/planar to SSR to probe,
high-order to basic refraction, and fewer FFT detail cascades. Failure never
substitutes an unrelated animated normal map for authoritative shape. Invalid
snapshot generation skips the surface pass with diagnostics rather than
sampling dangling handles.

Deterministic and testing strategy
----------------------------------

Image tests use fixed spectra/cameras/exposure. Unit/conformance tests cover
world-to-GPU coordinate split, displaced bounds, deep/coastal seam, shoreline
mask, Fresnel at normal/grazing angles, Snell refraction, Beer-Lambert thickness,
total internal reflection, s/p/Brewster/unpolarized Fresnel, optional Stokes
rotation/depolarization, BRDF/interface energy furnace, motion vectors, history
rejection, above/below-water crossing, origin shift, reversed-Z, and device
recreation. GPU captures verify resource states and absence of read/write races.

Performance and scalability
---------------------------

Use GPU indirect tile draws, occlusion/frustum culling, variable ring density,
async FFT, half precision only for validated detail fields, descriptor reuse,
and foveated/view-shared spectra where compatible. Scale reflection method,
grid density, high-frequency cascades, media resolution, and history quality.
Never scale away low-frequency geometry needed to align ships and shoreline.
Track FFT, cull, reflection, shade, overdraw, bandwidth, history reject rate,
and transient/persistent bytes per view.
File 90 gates optical reference error, energy excess, and per-tier GPU budget.

Integration points
------------------

Camera/Renderer supply views and opaque scene buffers. RenderGraph schedules
FFT, reflections, media, surface, transparencies, and postprocessing. Lighting
supplies sun/sky/probes. Effects supplies foam/spray interfaces. Terrain
supplies coastline depth/material. GraphicsQualityManager uses validated tiers in file
86. DebugDiagnostics visualizes cascades, normals, blend masks, optical path,
history validity, and pass timing.

Engine-wide integration contract
--------------------------------

Normative presentation-only pass/resource owner. P14/P15 consume immutable
OceanRenderSnapshot, ViewFamily, lighting, terrain, and effects values.
RenderGraph owns pass ordering/transients; this module owns persistent history
and transfers retired generations to FrameManager with GpuCompletionSet.
Render time/visual residuals/visibility/readback never feed P2-P12. See
..\rendering\INDEX.txt, ..\CANONICAL_CONVENTIONS.txt, and
88_ocean_gpu_execution_sync.txt.
