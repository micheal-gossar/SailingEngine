OCEAN UNITS, CONVENTIONS, AND INVARIANTS DESIGN
===============================================

Class
-----

    OceanContractRegistry

Purpose
-------

Define the non-negotiable units, coordinate/phase conventions, ownership rules,
generation semantics, and runtime invariants shared by every ocean module. A
module may use a packed internal form, but conversion at its boundary must be
explicit, versioned, and covered by conformance tests.

This document extends ..\CANONICAL_CONVENTIONS.txt. Where a root type exists
(EntityId, AssetId, TickId, WorldPosition, GpuTimelinePoint,
GpuCompletionSet, Result/Error, seed stream, SI axes), the root definition is
authoritative and this file may only add ocean fields/invariants.

Public API
----------

    Result<void, OceanContractError> RegisterModule(
        OceanModuleId, const OceanContractDeclaration&);
    Result<void, OceanContractError> ValidateSnapshot(
        const OceanGenerationTuple&) const;
    void CheckInvariant(OceanInvariantId, const OceanInvariantSample&);
    const OceanConventionVersion& Version() const;
    OceanOwnershipReport Ownership() const;

The registry validates declarations during initialization and feeds structured
invariant failures to OceanValidationAndQuality. It is not a service queried in
inner simulation or shader loops; generated constants and typed wrappers carry
the validated contract.

Key data structures
-------------------

OceanConventionVersion:
    Schema id plus coordinate, Fourier, datum, time, optical, acoustic, and
    deterministic-math versions. It is stored in saves and network manifests.

OceanGenerationTuple:
    Epoch, tick, forcing, spectrum, bathymetry, coastal, interaction, ecosystem,
    origin, quality, and publication generations.

Typed quantities:
    WorldLengthM, TimeS, VelocityMps, AccelerationMps2, MassKg, DensityKgM3,
    PressurePa, ForceN, EnergyJ, PowerW, TemperatureK, SalinityGKg,
    FrequencyHz, AngularFrequencyRadS, AngleRad, RadianceWm2Sr,
    AbsorptionMInv, SoundLevelDbRe1uPa, and Dimensionless.

Coordinate and unit conventions
-------------------------------

World space is right-handed: +X east, +Y north, +Z up. Horizontal vectors are
(X,Y). Angles are radians, positive counter-clockwise from +X when viewed from
+Z. Direction vectors point toward motion; meteorological "wind from" values
are converted once at WeatherSystem ingestion. Linear, momentum, and optical
calculations use SI units. Salinity is g/kg, temperature Kelvin internally,
pressure Pa absolute, sound pressure dB re 1 microPa, wavelength metres.

Sea-surface elevation eta and seabed elevation zb are metres relative to the
world vertical datum; water depth h=max(eta-zb,0). A positive boundary flux is
into the tile. Stress/pressure acts on water with its reaction separately
tagged. Texture V direction, NDC depth, reversed-Z, and Vulkan image origin are
renderer conversions and must never leak into physical coordinates.

CPU persistent positions are signed WorldCellKey plus double local metres,
canonicalized into [0, cellSize) on X/Y. GPU positions are float offsets from a
double high/low render origin and carry OriginGeneration. Time is an integer
OceanTick plus rational tick period from a UTC-related epoch; astronomical tide
phase conversion and leap-second table versions are persisted. Render time may
interpolate but may not become simulation time.

Fourier and spectrum conventions
--------------------------------

The forward transform is F(k)=sum_x f(x) exp(-i k dot x); inverse divides by
Nx*Ny and uses exp(+i k dot x). k is radians/metre, omega radians/second, and
frequency spectra document whether density is per Hz, rad/s, or wave-number
area. Array index-to-signed-wave-number mapping and Nyquist/DC treatment are
generated into CPU and shaders. For a real field H(-k)=conj(H(k)); self-
conjugate DC/Nyquist bins have zero imaginary part. Horizontal displacement,
slope, velocity, Jacobian, FFT normalization, and choppiness signs have one
golden convention.

Optical coefficients are wavelength-banded linear values, never gamma encoded.
Color buffers state radiometric/scene-linear or display encoding. Acoustic band
power sums in linear power; decibels are converted only at interfaces.

Algorithms and models
---------------------

Contract declarations name every input/output unit, datum, sign, time basis,
generation producer, force owner, CPU/GPU precision, and allowed interpolation.
Code generation emits CPU typed constants and shader include constants from the
same declaration. Validation hashes the generated convention block in captures,
saves, and network handshakes.

Global invariants:
    Exactly one owner mutates each authoritative state generation.
    Published snapshots are immutable and internally generation-coherent.
    Render/GPU state never feeds authoritative simulation through readback.
    Deep/coastal blend weights sum to one where water exists.
    Closed domains conserve water volume; source/reaction ledgers balance.
    Water depth is non-negative within the declared numerical epsilon.
    Spectrum conjugate symmetry and finite energy hold after every transition.
    Origin rebasing changes representation, never physical phase or position.
    Quality changes cannot change authoritative query hashes.
    Cohort plus promoted reservation counts equal the population ledger.
    Retired resources remain alive through every point in last-use
    GpuCompletionSet.

Update rates, threading, and GPU ownership
-----------------------------------------

Declarations freeze before world activation. Cheap invariants run at producer
publication; conservation/precision aggregates run at 1 Hz; expensive spectral
or GPU checks are sampled by validation policy. Invariant collection uses
thread-local bounded buffers and stable reduction. The registry owns metadata
only. Producing modules own state/resources; RenderGraph owns transient lifetime
and barriers; FrameManager drains persistent GPU retirement after each
GpuCompletionSet.

Lifecycle and dependencies
--------------------------

Create after configuration but before OceanDomain. All modules 72 through 90
must register before the first epoch is accepted. A save/network convention
version mismatch requires an explicit migration or refusal. Generated shader
constants are validated against the loaded ShaderPipelineManager reflection.
See ..\core\54_world_coordinate.txt, ..\core\37_simulation_clock.txt,
..\rendering\04_shader_pipeline_manager.txt, 72_ocean_domain_coordinator.txt,
86_ocean_validation_quality.txt, and 88_ocean_gpu_execution_sync.txt.

Failure and error behavior
--------------------------

Errors include DuplicateOwner, MissingUnit, DatumMismatch, ConventionMismatch,
IllegalInterpolation, InvalidGenerationDependency, ForceOwnerConflict,
ShaderContractMismatch, and InvariantViolation. Initialization errors prevent
world activation. A runtime invariant freezes the offending producer's last
valid generation, captures its inputs, and applies only a declared fallback.
NaN/Inf always fails publication; diagnostics must not sanitize it silently.

Deterministic and testing strategy
----------------------------------

Compile-time dimension tests reject invalid typed operations. Golden tests cover
axis/angle/wind conversion, datum/depth/flux signs, tick/epoch conversion,
negative cell canonicalization, high/low GPU split, Fourier impulse/sinusoid,
Nyquist/DC/conjugate pairs, FFT normalization, optical/acoustic unit conversion,
generation DAG validation, force ownership, origin invariance, save/network
version rejection, and generated CPU/shader constant identity.

Performance and scalability
---------------------------

Typed wrappers erase to primitive values in optimized builds. Publication checks
are O(number of pages/modules), not O(grid cells), unless sampling policy asks
for a deep audit. Metric buffers are fixed capacity and never block simulation.
Shipping keeps finite/generation/ownership/conservation summaries; detailed
cell/mode scans remain developer or sampled telemetry.

Integration points and acceptance
---------------------------------

Every ocean API documents its units by typed values or contract declaration.
Asset cooking stamps datum/convention versions. Save/network manifests include
the version/hash. Stage 0 acceptance requires all modules to register without
implicit units, CPU/shader Fourier vectors to match, and all global invariant
tests to pass before any physical or rendering implementation proceeds.

Engine-wide integration contract
--------------------------------

Normative ocean extension. Registration metadata is owned here; module state
stays with producers. Root phase/thread/lifetime/error rules in
..\FRAME_THREADING_MODEL.txt, ..\OWNERSHIP_LIFETIME_SHUTDOWN.txt, and
..\ERROR_RESULT_POLICY.txt cannot be weakened by an ocean fallback.
