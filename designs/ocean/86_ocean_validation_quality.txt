OCEAN VALIDATION, PROFILING, AND QUALITY CLASS DESIGN
=====================================================

Class
-----

    OceanValidationAndQuality

Purpose
-------

Define measurable physical, deterministic, synchronization, visual, ecological,
and performance acceptance criteria; capture provenance; and select scalable
quality without allowing visual tiers to change authoritative gameplay water.

Public API
----------

    Result<void, ValidationError> LoadQualityPolicy(
        const OceanQualityPolicy&);
    OceanQualityDecision Evaluate(const OceanCapabilityAndBudget&);
    void BeginCapture(const OceanCaptureDescription&);
    OceanCapture EndCapture();
    ValidationReport RunSuite(ValidationSuiteId);
    void RecordModuleMetrics(const OceanModuleMetrics&);
    void RegisterInvariant(const OceanInvariantDescription&);
    OceanHealthSnapshot Health() const;

Key data structures
-------------------

OceanQualityPolicy contains ordered feature tiers, CPU/GPU/memory/I/O budgets,
authoritative minimums, transition hysteresis, per-view rules, and device
capabilities. OceanCapture records epoch, ticks, seeds, module/schema versions,
input/observer streams, snapshot provenance, quality decisions, GPU/device
features, selected query vectors, conservation ledgers, and timings.
InvariantSample stores threshold, duration/hysteresis, source generation, and
diagnostic payload. ValidationReport separates pass/fail/unsupported and never
treats missing measurements as pass.

Algorithms and models
---------------------

Physical validation measures spectral significant wave height/period/direction,
Parseval energy, dispersion, tide gauges, current flux, coastal mass/momentum,
wave-action/shoaling/refraction/breaking, wake reaction/impulse, and optical
energy/transmittance. Ecological validation measures population non-negativity,
cohort/promoted conservation, trophic energy bounds, habitat capacity, movement
limits, and long-run statistical distributions.

CPU/GPU conformance samples a stratified deterministic set covering world-cell
extremes, crests/troughs, spectrum cascades, coastal blends, wet/dry cells,
wakes, origin generations, and time epochs. Compare packed inputs first, then
intermediate phase/modes, then outputs to locate divergence. Thresholds are per
field and precision path; a loose height-only screenshot comparison is
insufficient.

Synchronization validation tags every resource/snapshot with producer,
generation, origin, queue timeline, and lifetime. Debug runs poison retired
handles, randomize legal job scheduling, enable Vulkan validation, and capture
RenderGraph barriers. Invariants reject render-to-simulation readback,
mixed-generation queries, unretired origin transforms, mutable snapshots,
same-tick wake feedback, duplicate force ownership, and more than one coupling
submission between physics barriers.

Quality selection is capability plus measured-budget driven. It changes only
at tick/frame safe points with hysteresis and records every decision. Tiers:
    Authoritative minimum: forcing, CPU low modes, required coastal/wake/query.
    Low: 1-2 visual FFT cascades, coarse coast/media, statistical fauna.
    Medium: 3 cascades, active caustics/effects, group/agent fauna.
    High: 4+ cascades, dispersive surf tiles, richer media/habitats/agents.
    Cinematic: increased visual sampling only; no different gameplay physics.

Fallback order is transactional and fixed: reduce diagnostic readback; spray/
mist particles; caustic rays/update rate; froxel resolution; habitat geometry/
plant segments; small-fish full agents to school blocks; acoustic ray count;
far wake/foam visual resolution; far FFT update rate/high-frequency visual
cascades. It may then reduce the supported coastal/agent residency radius before
violating the authoritative safety ring. It never changes OceanEpoch, retained
physics modes, tide/current datum, required coastal cells, wake source/reaction,
population totals, or save/network state. Recovery uses hysteresis and warms a
new resource generation before swap.

Update rates, threading, and GPU ownership
-----------------------------------------

Lightweight invariants/metrics collect each tick/frame; health aggregates at
1 Hz; expensive validation suites run offline, at startup smoke mode, or by
developer command. GPU timestamp/query/readback rings are delayed and rate
limited. Validation owns readback staging and reports, not simulation/render
resources. Quality decisions are published to modules; modules perform their
own transactional resource changes.

Lifecycle and dependencies
--------------------------

Construct diagnostics before ocean modules, register module schemas/invariants
during initialization, and load a platform quality policy after device
selection. Shipping builds retain cheap safety/conservation/generation checks
and telemetry with privacy-safe bounded capture. Captures are versioned and
self-describing. See ..\diagnostics\15_debug_diagnostics.txt,
..\rendering\56_graphics_quality.txt, ..\vulkan\17_physical_device_selector.txt,
..\rendering\03_render_graph.txt, and every ocean file 72 through 85.

Failure and error behavior
--------------------------

Errors include UnknownMetricSchema, IncompatibleCapture, MissingProvenance,
InvariantViolation, UnsupportedCapability, BudgetUnsatisfiable, and
ConformanceFailure. An unsatisfied authoritative minimum prevents world start
or reduces supported vessel/coastal radius explicitly; it never silently swaps
to visual water. Repeated runtime violations freeze the affected module's last
valid generation, capture evidence, and degrade optional dependents. Profiling
query overflow drops low-priority metrics, not synchronization.

Deterministic and testing strategy
----------------------------------

Required suites:
    Spectrum: golden small FFT, energy, dispersion, weather transitions.
    Coast: lake-at-rest, run-up, harbor, seams, conservation, breaking.
    Query: scalar/SIMD/batch/GPU, inversion, origin/time extremes.
    Interaction: Kelvin/depth wake, source/reaction ledgers, handoff.
    Optics: Fresnel/Snell/Beer-Lambert, BRDF furnace, caustic energy.
    Streaming: churn, save interruption, schema, rebase/in-flight frames.
    Ecology: 24-hour/season accelerated runs and promotion conservation.
    Agents/acoustics: behavior bounds, LOD continuity, delay/attenuation.
    Soak: storms, many vessels/observers, device loss, memory pressure.

Interaction tests also vary physics/ocean scheduling to prove the N-to-N+1
contract and exactly-once force ownership. Network tests compare authority and
client query hashes across loss, correction, late join, and quality mismatch.
Numeric thresholds, the initial reference-high CPU/GPU/memory/transfer envelope,
and per-stage evidence are defined and versioned in
90_ocean_staged_acceptance.txt. A module cannot declare itself complete from an
unbudgeted microbenchmark or image-only comparison.

CI stores numeric reports and compact reference data; image goldens use fixed
exposure/device tolerance masks. Determinism runs vary worker count and render
frame cadence while requiring the same authoritative hashes.

Performance and scalability
---------------------------

Budgets report median, p95, p99 and worst burst for CPU coordinator/jobs, FFT,
coastal cells/substeps, query samples, wakes, media/effects, ecosystem/agents,
acoustics, draw/overdraw, memory, upload, I/O, and save. Automated stress sweeps
observer/vessel/sea-state/cell counts and detects complexity cliffs. Dynamic
quality lowers optional resolution, sample count, range, and update rate in a
documented order with hysteresis; allocation failure paths are tested.
Reports always include p50/p95/p99/worst, scenario/target, quality generation,
missed deadlines, queue overlap, CPU critical path (not summed worker time
alone), GPU total/individual passes, resident/peak memory, I/O/upload/readback,
conservation/error metrics, and whether fallback changed authoritative hashes.

Integration points
------------------

DebugDiagnostics displays health/invariants. GraphicsQualityManager provides user
intent but this class resolves it against physical minimums/capability/budget.
RenderGraph and CommandScheduler provide timestamps and synchronization traces.
All ocean modules publish standardized metrics/provenance. Test runners invoke
headless CPU suites and GPU conformance suites. Captures can reproduce one tick,
one frame, or a streamed time interval without requiring a save-game mutation.
OceanGpuExecutionPlan supplies barrier/timeline/readback metrics; BathymetryPipeline
supplies datum/seam/error metrics; OceanAcceptanceRunner owns the final stage
gate and evidence report.

Engine-wide integration contract
--------------------------------

Normative ocean validation/quality policy observer, not a resource or global
GraphicsQualityManager owner. It resolves ocean-specific minimums inside the
root GraphicsQualityDecision and publishes a transactional module plan. Diagnostics
and captures observe immutable values; fault injection cannot become a hidden
runtime dependency. Root lifecycle, Result/Error, timeline, and acceptance
rules are ..\INTEGRATION_ACCEPTANCE_MATRIX.txt,
..\ERROR_RESULT_POLICY.txt, and ..\CANONICAL_CONVENTIONS.txt.
