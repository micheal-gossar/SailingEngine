VIRTUAL FILESYSTEM CLASS DESIGN
===============================

Class:

    VirtualFileSystem

Purpose:

    Resolve normalized virtual paths across ordered directory/package mounts and provide safe synchronous metadata plus asynchronous reads.

Public API:

    Mount(name,source,priority)->Result<MountToken,VfsError>;
    Unmount(MountToken)->Result<void,VfsError>;
    Exists(VirtualPath)->Result<bool,VfsError>;
    Stat(VirtualPath)->Result<FileMetadata,VfsError>;
    Read(VirtualPath,ReadLimits)->Result<ByteBuffer,VfsError>;
    ReadAsync(VirtualPath,ReadLimits,CancellationToken)->Future<Result<ByteBuffer,VfsError>>;
    Enumerate(VirtualPath prefix)->Result<vector<VirtualPath>,VfsError>;
    Watch(VirtualPath prefix,callback)->Result<WatchToken,VfsError>;

Internal state and components:

    - mount table.
    - canonical virtual path parser.
    - package indices.
    - read cache.
    - watcher registrations.
    - I/O request queue.

Lifecycle and ownership:

    mounts owned by VFS; returned buffers own bytes; async request retains mount snapshot; unmount waits/cancels outstanding backend operations

Error behavior:

    Invalid/traversal path, stale mount, not found, permission, cancellation,
    size/ratio limit, corrupt package, and backend I/O return VfsError. No empty
    buffer represents a failed read.

Threading and timing constraints:

    metadata is thread-safe; blocking Read forbidden on render/simulation threads; callbacks delivered through main-thread queue

Dependencies:

    - JobSystem.
    - DebugDiagnostics.

Tests:

    - path traversal rejection.
    - mount priority.
    - case policy.
    - package read.
    - cancel.
    - unmount during read.
    - watcher coalescing.
    - corrupt archive.

Implementation rules:

    - Keep implementation-only types out of public headers.
    - Use RAII and generational IDs; do not expose owning raw pointers.
    - Validate descriptions before allocating or mutating state.
    - Publish complete snapshots/generations rather than partially updated data.
    - Add diagnostics for failure context without making logging a dependency
      of correctness.

Canonical integration contract:

    Normative I/O boundary. VirtualPath uses one normalized separator/case
    policy and cannot escape a mount. Every read declares compressed and
    decompressed byte limits before allocation. Blocking Read is startup/tool/
    worker-only. Watch callbacks enqueue bounded value events and are
    `noexcept`; main-thread consumers poll them.

    See ..\ERROR_RESULT_POLICY.txt, ..\FRAME_THREADING_MODEL.txt, and INDEX.txt.
