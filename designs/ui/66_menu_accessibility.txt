MENU ACCESSIBILITY CLASS DESIGN
===============================

Class:

    MenuAccessibilitySystem

Purpose:

    Coordinate menus, rebinding, settings staging, localization-ready labels, focus, and accessibility transforms.

Public API:

    Open(menu,args);
    Close(menu);
    StageSetting(key,value);
    Apply();
    Cancel();
    BeginRebind(action);
    HandleRebindInput(event);
    AccessibilitySnapshot();

Internal state and components:

    - menu stack.
    - settings transaction.
    - binding-conflict model.
    - focus graph.
    - text scale/color/motion/subtitle options.
    - confirmation timer.

Lifecycle and ownership:

    staged settings isolated until Apply; rebind capture RAII and always restores input context; persisted through ConfigurationSettings

Error behavior:

    Invalid menu/setting/binding/conflict, stale transaction, and display apply
    failure return AccessibilityError. Apply is transactional; display rollback
    timeout restores the prior validated settings generation.

Threading and timing constraints:

    main thread; display-mode confirmation uses monotonic timer; callbacks enqueue changes, never re-enter menu mutation

Dependencies:

    - UISystem.
    - InputActionSystem.
    - ConfigurationSettings.
    - GraphicsQualityManager.

Tests:

    - apply/cancel.
    - invalid setting.
    - binding conflict.
    - rebind cancel.
    - focus traversal.
    - text scale.
    - display rollback timeout.

Implementation rules:

    - Keep implementation-only types out of public headers.
    - Use RAII and generational IDs; do not expose owning raw pointers.
    - Validate descriptions before allocating or mutating state.
    - Publish complete snapshots/generations rather than partially updated data.
    - Add diagnostics for failure context without making logging a dependency
      of correctness.

Canonical integration contract:

    Normative menu/staging owner. Main-thread P13 produces immutable
    AccessibilitySnapshot consumed by UI/HUD/audio/render presentation only.
    Settings and input bindings remain owned by ConfigurationSettings and
    InputActionSystem; this class owns staged values/capture tokens. Reduced
    motion, text scale, color, subtitle, and audio accessibility never alter
    authoritative simulation or deterministic replay.

    See ..\core\31_configuration_settings.txt,
    ..\platform\11_input_action_system.txt, and 36_ui_system.txt.
