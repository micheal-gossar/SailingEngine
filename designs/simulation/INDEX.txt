SIMULATION SUBSYSTEM INDEX
==========================

Authorities
-----------

EntityRegistry owns EntityId and component storage. CollisionSystem owns
immutable generation-checked shape records. PhysicsWorld owns BodyId, backend
bodies, constraints, force accumulators, and ordered events. AnimationSystem
owns animation instances and publishes root-motion/events at fixed ticks plus
visual palette snapshots.

Documents
---------

12_entity_registry.txt, 24_physics_world.txt, 39_collision_system.txt, and
40_animation_system.txt.

Dependency and phase rules
--------------------------

CollisionSystem does not depend on PhysicsWorld; PhysicsWorld retains
ShapeHandle. EntityRegistry never owns backend bodies or render resources.
Structural changes queue for the P7 boundary. Physics advances only FixedDelta
and callbacks enqueue value events. Animation gameplay events/root motion use
fixed ticks; palette interpolation is visual and cannot drive entities.

External systems map EntityId to their own typed IDs and remove mappings before
entity generation reuse. World rebase is a transaction through
core\54_world_coordinate.txt; no subsystem reaches into another's mutable
storage. See ..\FRAME_THREADING_MODEL.txt.
