VULKAN SUBSYSTEM INDEX
======================

Canonical ownership chain
-------------------------

    WindowPlatform -> VulkanRuntime
    VulkanRuntime -> CommandScheduler + MemoryManager
    CommandScheduler -> per-queue GpuTimelinePoint
    FrameManager -> FrameSlot + GpuRetirementQueue
    GpuResourceManager -> resource/allocation generations
    DescriptorAllocator -> descriptor generations
    SwapchainManager -> presentation generations
    RenderGraph (rendering\03) -> normal-frame synchronization

Documents
---------

02_gpu_resource_manager.txt owns typed GPU records, uploads, explicit state, and
last-use completion sets. 16_vulkan_runtime.txt owns bootstrap RAII.
17_physical_device_selector.txt is stateless bootstrap policy.
19_command_scheduler.txt owns queues/pools/timeline values.
20_frame_manager.txt owns slots and deferred retirement, not timeline allocation.
21_swapchain_manager.txt owns swapchain generations and presentation status.
22_descriptor_allocator.txt owns descriptor pools/layout/set generations.

Cycle breaks
------------

CommandScheduler has no FrameManager dependency. SwapchainManager and
DescriptorAllocator receive FrameSlotId/GpuCompletionSet values and have no
FrameManager dependency. PhysicalDeviceSelector receives instance/surface
bootstrap data and has no VulkanRuntime dependency. ShaderPipelineManager uses
DescriptorAllocator/layout services; descriptor allocation never depends on a
shader manager. WindowPlatform does not depend on VulkanRuntime.

Synchronization rule
--------------------

No manager inserts an undeclared hidden transition or normal-frame wait.
RenderGraph declares stage/access/layout and queue transfers; CommandScheduler
submits it; FrameManager retires only after all queue points complete. See
..\CANONICAL_CONVENTIONS.txt and ..\OWNERSHIP_LIFETIME_SHUTDOWN.txt.
