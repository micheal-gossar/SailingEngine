SWAPCHAIN MANAGER CLASS DESIGN
==============================

Class:

    SwapchainManager

Purpose:

    Create and recreate swapchain images/views from current surface capabilities without leaking in-flight resources.

Public API:

    Create(extent,preferences)->Result<void,SwapchainError>;
    Acquire(FrameSlotId) -> AcquireStatus;
    Present(QueueId,imageIndex,const GpuTimelinePoint& renderComplete);
    PrepareRecreate(extent)->Result<SwapchainGeneration,SwapchainError>;
    CommitRecreate(SwapchainGeneration,GpuCompletionSet oldLastUse);
    Format() const;
    Extent() const;
    Images() const;

Internal state and components:

    - vk::raii::SwapchainKHR.
    - non-owned swapchain images.
    - owned views.
    - format/colorspace/present mode/extent.
    - generation.
    - old generation retirement.

Lifecycle and ownership:

    Renderer owns manager; VulkanRuntime outlives it. Views die before their
    swapchain; old generations are move-only retirement payloads held by
    FrameManager until GpuCompletionSet completes. Zero extent is Suspended
    status and defers creation.

Error behavior:

    OutOfDate, Suboptimal, SurfaceLost, and ZeroExtent are status/error values,
    never exceptions. Failed recreation retains the last valid generation when
    usable. Device loss preserves original VkResult/context.

Threading and timing constraints:

    render thread only; recreation occurs at frame boundary; acquire/present status is data, not an exception for resize/suboptimal

Dependencies:

    - VulkanRuntime.
    - WindowPlatform.
    - CommandScheduler.
    - GpuRetirementQueue interface supplied by Renderer.

Tests:

    - format/present fallback.
    - image count clamp.
    - resize/out-of-date.
    - zero extent.
    - old generation retirement.
    - surface lost.

Implementation rules:

    - Keep implementation-only types out of public headers.
    - Use RAII and generational IDs; do not expose owning raw pointers.
    - Validate descriptions before allocating or mutating state.
    - Publish complete snapshots/generations rather than partially updated data.
    - Add diagnostics for failure context without making logging a dependency
      of correctness.

Canonical integration contract:

    Normative presentation owner. It does not own frames or timeline values.
    Acquire/present binary semaphores are bridged by CommandScheduler to
    qualified timeline points. Recreate occurs at P15, never calls device idle,
    and publishes a complete generation atomically. Borrowed swapchain VkImage
    handles never enter the general resource allocator as owned images.

    See INDEX.txt, 19_command_scheduler.txt, 20_frame_manager.txt, and
    ..\ERROR_RESULT_POLICY.txt.
