FRAME MANAGER CLASS DESIGN
==========================

Class:

    FrameManager

Purpose:

    Coordinate bounded frames in flight, per-frame resources, synchronization, and deferred retirement.

Public API:

    BeginFrame(const CompletedGpuTimelines&) -> Poll<FrameContext>;
    EndFrame(FrameContext&&,PresentRequest)
        -> Result<FrameCompletion,GpuError>;
    CurrentIndex() const;
    FramesInFlight() const;
    DeferDestroy(GpuCompletionSet,MoveOnlyRetirementPayload);
    Collect(const CompletedGpuTimelines&);
    Drain(ShutdownOrRecoveryToken);

Internal state and components:

    - frame slots with FrameSlotId, last GpuCompletionSet, query ranges, and
      caller-owned arena reset tokens.
    - one GpuRetirementQueue ordered by qualified completion sets.
    - submitted frame number.

Lifecycle and ownership:

    FrameContext is move-only and valid until EndFrame. Slot reset occurs only
    after polling confirms its GpuCompletionSet; normal BeginFrame does not hide
    a host wait. Manager drains retirement payloads before GPU owners die.

Error behavior:

    All slots busy is Poll::Pending/back-pressure, not an implicit wait.
    Invalid context/slot, duplicate end, acquire/present status, and device loss
    are typed values. A retirement callback is `noexcept`; callback failure is
    diagnosed and containment continues.

Threading and timing constraints:

    render thread only; at most configured frames active; simulation does not wait on presentation; minimized windows may skip GPU frame

Dependencies:

    - CommandScheduler.
    - Swapchain acquire/present interface (non-owning).
    - DebugDiagnostics.

Tests:

    - two/three-frame reuse.
    - deferred callback timing.
    - skipped frame.
    - acquire out-of-date.
    - device loss.
    - drain order.

Implementation rules:

    - Keep implementation-only types out of public headers.
    - Use RAII and generational IDs; do not expose owning raw pointers.
    - Validate descriptions before allocating or mutating state.
    - Publish complete snapshots/generations rather than partially updated data.
    - Add diagnostics for failure context without making logging a dependency
      of correctness.

Canonical integration contract:

    Normative frame-slot and deferred-destruction owner. CommandScheduler owns
    timeline semaphores/values; FrameManager only stores/polls completion sets.
    Descriptor/upload/query arenas register slot reset hooks and do not create
    ownership cycles. All GPU owners enqueue move-only RAII payloads here; no
    second DeferredDeletionQueue exists in MemoryManager, GpuResourceManager,
    swapchain, shaders, materials, textures, meshes, or ocean modules.

    See ..\OWNERSHIP_LIFETIME_SHUTDOWN.txt, 19_command_scheduler.txt,
    21_swapchain_manager.txt, and 22_descriptor_allocator.txt.
