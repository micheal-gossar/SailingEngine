VULKAN RUNTIME CLASS DESIGN
===========================

Class:

    VulkanRuntime

Purpose:

    Own the self-building Vulkan instance-to-device bootstrap and expose only fully initialized RAII handles.

Public API:

    static Result<VulkanRuntime,VulkanError> Create(
        WindowPlatform::Window&, RuntimeOptions);
    Instance() const;
    PhysicalDevice() const;
    Device() const;
    Queues() const;
    WaitIdle(ShutdownOrRecoveryToken);
    Capabilities() const;

Internal state and components:

    - vk::raii::Context/Instance/DebugUtilsMessengerEXT/SurfaceKHR/Device.
    - queue handles.
    - capability snapshot.
    - private OperationRunner.

Lifecycle and ownership:

    Window outlives Runtime because Runtime owns the Vulkan surface created from
    it. Runtime owns all bootstrap Vulkan objects in reverse dependency order;
    no partially initialized object escapes.

Error behavior:

    Creation is transactional and returns VulkanError with original VkResult,
    operation, validation sequence, and rejected capability context. DeviceLost
    is preserved. Vulkan debug and allocation callbacks are `noexcept`; no C
    callback observes an exception.

Threading and timing constraints:

    Initialization is single-threaded; runtime access is read-only after
    construction. WaitIdle requires an explicit shutdown/recovery token and is
    prohibited for normal frames, resize, reload, upload, or resource release.

Dependencies:

    - WindowPlatform::Window.
    - OperationRunner.
    - PhysicalDeviceSelector bootstrap helper.
    - DebugDiagnostics.

Tests:

    - construct valid runtime.
    - missing extension/layer diagnostics.
    - partial-failure cleanup.
    - queue capability exposure.
    - validation-message association.

Implementation rules:

    - Keep implementation-only types out of public headers.
    - Use RAII and generational IDs; do not expose owning raw pointers.
    - Validate descriptions before allocating or mutating state.
    - Publish complete snapshots/generations rather than partially updated data.
    - Add diagnostics for failure context without making logging a dependency
      of correctness.

Canonical integration contract:

    Normative Vulkan root only. It does not own MemoryManager,
    GpuResourceManager, CommandScheduler, FrameManager, SwapchainManager,
    DescriptorAllocator, or RenderGraph; Renderer/ApplicationHost construct
    those after Runtime and destroy them first. Queue handles are borrowed by
    CommandScheduler, which solely owns timeline semaphores/value allocation.

    See INDEX.txt, ..\OWNERSHIP_LIFETIME_SHUTDOWN.txt,
    ..\ERROR_RESULT_POLICY.txt, and ..\platform\18_window_platform.txt.
