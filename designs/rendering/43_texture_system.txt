TEXTURE SYSTEM CLASS DESIGN
===========================

Class:

    TextureSystem

Purpose:

    Load, transcode, upload, stream, and sample texture assets with format/color-space correctness.

Public API:

    Load(assetId,usage)->TextureHandle;
    Create(desc,pixels);
    RequestMip(handle,maxMip);
    View(handle) const;
    Sampler(desc);
    ReleaseMipBudget(bytes);
    Default(usage);

Internal state and components:

    - image/view allocations.
    - metadata dimensions/mips/format/colorspace.
    - sampler cache.
    - residency state.
    - upload tickets.
    - fallback descriptors.

Lifecycle and ownership:

    handles retain logical texture; GPU generations deferred on replacement/eviction; mapped staging is scoped

Error behavior:

    Invalid/stale handle, corrupt dimensions/mips, format/colorspace mismatch,
    unsupported transcode, upload/descriptor/budget, and GPU failure return
    TextureError. Default textures are explicit per-usage AssetIds.

Threading and timing constraints:

    decode/transcode on jobs; uploads scheduled; descriptor publication at frame boundary; mip requests thread-safe/coalesced

Dependencies:

    - AssetManager.
    - GpuResourceManager.
    - CommandScheduler.
    - DescriptorAllocator.
    - VirtualFileSystem.

Tests:

    - sRGB vs linear.
    - mip size validation.
    - compressed fallback.
    - partial residency.
    - sampler canonicalization.
    - corrupt data.
    - hot reload.

Implementation rules:

    - Keep implementation-only types out of public headers.
    - Use RAII and generational IDs; do not expose owning raw pointers.
    - Validate descriptions before allocating or mutating state.
    - Publish complete snapshots/generations rather than partially updated data.
    - Add diagnostics for failure context without making logging a dependency
      of correctness.

Canonical integration contract:

    Normative TextureHandle owner. AssetManager owns cooked bytes; this system
    owns image/view/sampler-facing logical generations, while sampler cache
    storage is delegated to GpuResourceManager. Decode/transcode is job-only;
    upload/descriptor publication is P13/P15. Residency and hot reload retain
    prior frame bindings through GpuCompletionSet; no descriptor points to a
    retired image. Colorspace is part of the asset/view contract and fallback.

    See ..\assets\INDEX.txt, ..\vulkan\02_gpu_resource_manager.txt, and INDEX.txt.
