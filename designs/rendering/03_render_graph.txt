RENDER GRAPH CLASS DESIGN
=========================

Class:

    RenderGraph

Purpose:

    Describe frame passes and resource dependencies, calculate execution order,
    allocate transient resources, generate barriers, and record commands.

Public API:

    RenderGraphBuilder BeginFrame(const FrameContext& frame);
    Result<CompiledRenderGraph,RenderGraphError> Compile(
        RenderGraphBuilder&& builder);
    Result<GpuCompletionSet,GpuError> Execute(
        CompiledRenderGraph&& graph, CommandScheduler& scheduler);

Pass declaration:

    builder.AddPass<PassData>(
        "Ocean",
        setupFunction,
        executeFunction);

Setup declares:

    Images/buffers read.
    Images/buffers written.
    Exact synchronization2 stages, access, and image layouts.
    Attachment load/store behavior.
    QueueId/capability and resource generation.

Execute receives:

    Resolved resource handles.
    Command buffer.
    Read-only pass data.

Internal compilation:

    Build pass dependency edges.
    Reject read-before-write for transient resources.
    Detect cycles.
    Cull passes whose outputs are unused.
    Topologically sort passes.
    Calculate resource lifetimes.
    Alias compatible transient resources.
    Generate synchronization2 barriers.
    Plan cross-queue release/acquire and timeline dependencies.

Initial passes:

    ShadowMap
    OpaqueWorld
    SkyAtmosphere
    Ocean
    TransparentParticles
    PostProcess
    UserInterface
    Present

Rules:

    Pass callbacks cannot retain frame-local resource references.
    Imported resources declare their initial and final states.
    Each write has a single ordered producer.
    Debug builds validate stage/access/layout combinations.
    Compilation errors include pass and resource names.

Errors:

    DuplicateResourceName
    UnknownResource
    ReadBeforeWrite
    DependencyCycle
    IncompatibleAliasing
    UnsupportedQueueTransition

Debug features:

    Export graph to DOT.
    Display pass timings.
    Disable selected optional passes.
    Disable aliasing for diagnosis.
    Name transient Vulkan objects.

Tests:

    Sort a linear pass chain.
    Sort independent branches.
    Detect a cycle.
    Reject uninitialized transient reads.
    Verify barrier generation.
    Verify resource lifetime overlap.
    Verify unused pass culling.

Dependencies:

    GpuResourceManager
    CommandScheduler
    FrameContext value supplied by FrameManager
    DebugDiagnostics

Canonical integration contract:

    Normative sole normal-frame synchronization authority. It owns per-frame
    declarations, compiled DAG, transient resources, barriers, and queue-transfer
    plan only. Persistent resources stay with their typed owners. Compile
    imports each resource's generation/last compiled state and emits all
    stage/access/layout transitions; managers/pass callbacks may not insert
    hidden waits or ownership transfers. Execute returns the qualified
    GpuCompletionSet used for frame/resource retirement.

    Builder/compiled objects are render-thread/frame-local. Pass callbacks are
    `noexcept` containment boundaries for recording and cannot retain resolved
    resources. See ..\CANONICAL_CONVENTIONS.txt,
    ..\vulkan\19_command_scheduler.txt, and ..\vulkan\20_frame_manager.txt.
