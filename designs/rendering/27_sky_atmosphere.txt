SKY ATMOSPHERE CLASS DESIGN
===========================

Class:

    SkyAtmosphereSystem

Purpose:

    Generate physically based sky, aerial perspective, sun lighting, and reflection inputs from atmosphere parameters.

Public API:

    SetParameters(params);
    Update(timeOfDay,weather);
    AddPasses(renderGraph,view);
    SunDirection() const;
    SunIlluminance() const;
    EnvironmentMap() const;
    InvalidateLuts();

Internal state and components:

    - transmittance/multiscatter/sky-view/aerial LUTs.
    - parameter hash.
    - sun state.
    - environment cubemap.
    - dirty generations.

Lifecycle and ownership:

    system owns LUT images/pipelines; published environment handle remains valid through frame; regeneration swaps after completion

Error behavior:

    Invalid physical parameters, stale input generation, capability/budget, and
    GPU failures return SkyError. Optional LUT fallback is named, capability
    tagged, and retains the last valid environment generation.

Threading and timing constraints:

    parameter updates thread-safe via snapshot; LUT compute scheduled on render queue; expensive rebuilds rate-limited

Dependencies:

    - RenderGraph.
    - TimeOfDay/Weather immutable P4 snapshots.
    - TextureSystem.
    - LightingShadowSystem consumes SkyLightingSnapshot; no reverse dependency.

Tests:

    - LUT invalidation.
    - sun horizon continuity.
    - weather blending.
    - resource recreation.
    - fallback without compute.
    - numeric bounds.

Implementation rules:

    - Keep implementation-only types out of public headers.
    - Use RAII and generational IDs; do not expose owning raw pointers.
    - Validate descriptions before allocating or mutating state.
    - Publish complete snapshots/generations rather than partially updated data.
    - Add diagnostics for failure context without making logging a dependency
      of correctness.

Canonical integration contract:

    Normative render pass provider. It owns only atmospheric GPU/LUT history and
    publishes immutable SkyLightingSnapshot (sun direction/illuminance and
    environment handle) for LightingShadowSystem. P4 simulation snapshots are
    copied at P12; all LUT/render work is P14-P16. World axes/radians/SI
    radiometry follow root conventions; no rendered cloud/sky value feeds
    WeatherSystem.

    See ..\FRAME_THREADING_MODEL.txt, 45_lighting_shadow.txt, and INDEX.txt.
