SHADER AND PIPELINE MANAGER CLASS DESIGN
========================================

Class:

    ShaderPipelineManager

Purpose:

    Load compiled SPIR-V, reflect shader interfaces, build Vulkan pipelines,
    cache compatible objects, and support safe development-time reload.

Public API:

    Result<ShaderHandle,ShaderError> LoadShader(AssetId asset);
    Result<PipelineHandle,ShaderError> GetGraphicsPipeline(
        const GraphicsPipelineDescription& description);
    Result<PipelineHandle,ShaderError> GetComputePipeline(
        const ComputePipelineDescription& description);
    Result<PipelineLayoutSnapshot,ShaderError> GetLayout(
        PipelineHandle pipeline) const;
    ReloadResult ReloadChangedShaders();
    void SavePipelineCache();

Shader record:

    Stage.
    SPIR-V bytecode/hash.
    Entry point.
    Reflected descriptor bindings.
    Push constants.
    Vertex inputs.
    Dependency files.
    Revision.

Pipeline key:

    Shader revisions.
    Render-target formats.
    Depth/stencil format.
    Vertex layout.
    Raster/depth/blend state.
    Specialization constants.
    Pipeline layout.

Build behavior:

    Validate SPIR-V alignment and magic number.
    Reflect every stage.
    Merge descriptor bindings.
    Reject incompatible binding declarations.
    Build/cache descriptor set layouts.
    Build/cache pipeline layouts.
    Create pipeline and assign debug name.

Reload behavior:

    Compile/load changed shader.
    Validate reflected compatibility.
    Build replacement pipelines.
    Swap only after all replacements succeed.
    Keep the last valid pipeline after a failure.
    Transfer old pipeline/layout payloads with last-use GpuCompletionSet to the
    FrameManager-owned retirement queue.

Errors:

    ShaderNotFound
    InvalidSpirv
    ReflectionFailed
    InterfaceMismatch
    PipelineCreationFailed
    ReloadRejected

Rules:

    Runtime never consumes source shader text.
    Build system compiles shaders to SPIR-V.
    Cache keys include all state affecting compatibility.
    Pipeline handles are generation checked.

Tests:

    Reflect known shader bindings.
    Reject conflicting bindings.
    Verify equal descriptions reuse pipeline.
    Verify format change creates a new pipeline.
    Failed reload preserves old pipeline.
    Pipeline cache loads and saves safely.

Dependencies:

    GpuResourceManager
    AssetManager
    DescriptorAllocator
    GpuRetirementQueue interface
    DebugDiagnostics

Canonical integration contract:

    Normative owner of ShaderHandle/PipelineHandle records and Vulkan shader/
    pipeline/layout payloads. AssetManager owns cooked SPIR-V bytes; descriptor
    allocator owns descriptor pools/layout cache records; no reverse descriptor
    dependency exists. Pipeline cache I/O is bounded and uses VirtualFileSystem.
    Runtime never compiles source text. Publication/reload occurs at P13;
    render passes retain immutable pipeline generations through completion.

    All Vulkan/backend failures return Result with original context. Reflection
    is validated against complete descriptor/push/vertex interfaces; fallback
    pipelines are named AssetIds, not silent success. See
    ..\ERROR_RESULT_POLICY.txt, ..\vulkan\22_descriptor_allocator.txt, and
    ..\assets\INDEX.txt.
