SAILING SUBSYSTEM INDEX
=======================

Coordinator and order
---------------------

VesselSystem is the P6/P8 coordinator; it does not own peers through reverse
calls. Per tick:
    controls -> environment/ocean batch -> damage mass modifiers ->
    sail/rudder/buoyancy/hydrodynamic/anchor forces -> PhysicsWorld ->
    post-step kinematics/events -> next-tick changes.

Contracts
---------

All IDs are EntityId or a typed generation handle. All geometry/forces use SI
and WorldPosition. Buoyancy, hydrodynamics, and rudder consume one coherent
OceanQueryService OceanSimulationView generation N. Each returned ForceSet
records provenance and exactly one application owner. Ocean wake reactions
tagged N+1 apply once in the next P6; same-tick re-query is prohibited.

Force modules consume VesselStepContext values and cannot call/mutate
VesselSystem. Player, AI, UI, and network code enqueue commands through
GameplayCommandBus. See ..\FRAME_THREADING_MODEL.txt and
..\ocean\71_ocean_architecture_index.txt.
